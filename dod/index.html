dod_string¶

Returns a pretty-printed string representation of a dictionary of dictionaries.

from pydicts import dod

sample_dod = {
    "emp_1": {"name": "Alice", "role": "admin"},
    "emp_2": {"name": "Bob", "role": "developer"},
}
formatted_str = dod.dod_string(sample_dod, indent=2)
print(formatted_str)
{ 'emp_1': {'name': 'Alice', 'role': 'admin'},
  'emp_2': {'name': 'Bob', 'role': 'developer'}}

dod_print¶

Prints a dictionary of dictionaries (DoD) in a human-readable, pretty-printed format.

from pydicts import dod
help(dod.dod_print)
Help on function dod_print in module pydicts.dod:

dod_print(dod_: dict, indent: int = 4, depth: Optional[int] = None, width: Optional[int] = None, sort_dicts: bool = True) -> None
    Prints a dictionary of dictionaries (DoD) in human-readable pretty-printed format.

    Args:
        dod_ (dict): The dictionary of dictionaries to print.
        indent (int, optional): The number of spaces to indent each level. Defaults to 4.
        depth (int, optional): The maximum depth to recurse when pretty-printing.
                               If None, there is no limit. Defaults to None.
        width (int, optional): The maximum desired output width. If None, uses terminal width. Defaults to None.
        sort_dicts (bool, optional): If True, dictionary keys are sorted alphabetically. Defaults to True.

    Returns:
        None


from pydicts import dod
from datetime import date, datetime
from decimal import Decimal
d={"a": datetime.now(), "b": date.today(), "c": Decimal('12.32'), "d": None, "e": int(12), "f":None, "g":True, "h":False,  "nested": {"x":1, "y":2, "z":{"n":4, "m":5, "o":6}}}
dod_={}
dod_["first"]=d
dod_["second"]=d
dod.dod_print(dod_)

dod_string_tables and dod_print_tables¶

Formats and prints the DoD as a table, placing dictionary keys as the first column:

from pydicts import dod

sample_dod = {
    "emp_1": {"name": "Alice", "role": "admin", "active": True},
    "emp_2": {"name": "Bob", "role": "developer", "active": True},
}
# Print directly as a table
dod.dod_print_tables(sample_dod, key_name="ID")

# Or obtain the table string representation
table_str = dod.dod_string_tables(sample_dod, key_name="ID")
┌───────┬────────┬───────────┬──────────┐
│ ID    │ name   │ role      │ active   │
├───────┼────────┼───────────┼──────────┤
│ emp_1 │ Alice  │ admin     │ True     │
├───────┼────────┼───────────┼──────────┤
│ emp_2 │ Bob    │ developer │ True     │
└───────┴────────┴───────────┴──────────┘
